Resumen ejecutivo

  • Diseño experimental. Se ejecutaron las 140 combinaciones del enunciado con validación anidada temporal completa (3 bloques externos de 12 meses × 3 pliegues internos, 15 evaluaciones por optimizador). Las reglas de reducción del cap. 13 (equivalencia y tamizaje) se mantuvieron como experimento y se verificaron con los resultados completos (cap. 14.7).

  • Evaluación final (cap. 13.11). Origen móvil 2021–2026: cada año los modelos se reentrenan con todo el pasado y pronostican ese año (69 meses); hiperparámetros y campeones de cada familia fijados con datos anteriores a 2016. Se evaluaron las 28 combinaciones de regresión y 26 de clasificación (7 modelos × 4 balanceos con TPE, sin los pares equivalentes; cap. 13.12).

  • Clasificación (¿habrá al menos un sismo el mes siguiente?). El mejor campeón es XGBoost (class_weight), AUC 0.810; marcando cada mes la proporción histórica de celdas activas alcanza recall 0.56. El balanceo no mejora el AUC de los modelos fuertes y descalibra las probabilidades; Platt e isotónica, ajustadas con años anteriores, lo corrigen (cap. 17).

  • Regresión (¿cuántos sismos?). XGBoost y Random Forest encabezan las 28 combinaciones; el campeón de XGBoost (TPE) obtiene RMSLE 0.3270 (cap. 18).

  • Modelo propuesto A+B v2 (boosting ZINB, combinador contextual y calibración final propios), con predicciones fuera de pliegue cronológicas: RMSLE 0.3260, el menor de todos.

    • Frente al campeón de cada familia (Holm, 7 comparaciones): gana a 7 de 7 (frente a XGBoost: p Holm = 0.003, d de Cohen = 0.36).

    • Pruebas alternativas frente a los mismos 7 campeones: Giacomini-White significativo en 7 de 7 y Clark-West en 7 de 7; con Holm sobre la familia completa de 21 contrastes (DM, GW y CW) el mayor p ajustado es 0.0057.

    • MCS al 90 % (7 campeones, A+B v2 y líneas base): A+B v2 (propuesto).

    • Ablación: sin el componente propio B el RMSLE sube a 0.3267 (p DM = 0.001).

    • Lectura: superioridad clara sobre Random Forest, KNN, árbol, SVR, Ridge y Lasso; frente a XGBoost la ventaja es significativa pero pequeña (≈ 0.3 % de RMSLE frente a su campeón) (cap. 21 y 22).

  • Optimización. Bayesiano (TPE) es el más eficiente por unidad de presupuesto, aunque solo se distingue con significancia de Grid. En la métrica externa los cuatro optimizadores quedan prácticamente empatados. La multi-fidelidad ahorra cómputo y no mejora la métrica (cap. 14 y 15).

  • Cómputo. Las versiones optimizadas (XGBoost hist con early stopping, LinearSVC/SGD, FAISS) reducen el tiempo hasta un orden de magnitud o más sin perder desempeño. El cuello de botella real es el ajuste de los modelos, no el preprocesamiento (cap. 16).

Limitaciones#

  • Enjambres. Ningún modelo anticipa el inicio de un enjambre; con información solo hasta el cierre del mes t eso parece un límite del problema, no de los modelos (cap. 18 y 19).

  • Tamaño del efecto. Las diferencias significativas entre los mejores modelos son pequeñas (d de Cohen y δ de Cliff pequeños o despreciables); la significancia se debe a que son sistemáticas, no grandes.

  • Costo. A+B v2 cuesta decenas de veces más que XGBoost.

  • Tiempos. Los tiempos de la validación anidada se midieron con varias combinaciones en paralelo y tienen ruido de contención; las comparaciones de tiempo finas se hicieron aparte (cap. 16).

Cómo reproducir el Entregable 2#

python scripts/correr_experimentos.py --tarea reg --fase todo      # 28 combinaciones de regresión
python scripts/correr_experimentos.py --tarea clf --fase todo      # tamizaje + 84 de clasificación
python scripts/correr_experimentos.py --tarea clf --fase 2 --todas # las 28 restantes (140 en total)
python scripts/xgboost_gpu.py                                      # CPU vs GPU (requiere CUDA)
python scripts/miembros_fuera_de_pliegue.py                       # miembros: predicciones fuera de pliegue (< 2021)
python scripts/origen_movil.py                                     # origen móvil: hiperparámetros < 2016 y miembros
python scripts/origen_movil_benchmark.py                           # origen móvil: 28 combinaciones
python scripts/origen_movil_final.py                               # origen móvil: modelo propuesto final y su ablación
python scripts/validacion_previa_final.py                          # validación previa del modelo final (< 2021)
python scripts/origen_movil_clasificacion.py                       # origen móvil: 26 combinaciones de clasificación
python scripts/semillas_origen_movil.py                            # sensibilidad a la semilla (cap. 20.2)
python scripts/experimentos_e2.py                                  # experimentos de los cap. 14, 15, 16 y 20
python scripts/independencia_residuos.py                           # pruebas de independencia (cap. 21.8)
python herramientas/construir_notebooks.py                         # ejecuta y convierte todos los capítulos
jupyter-book build .

Todos los scripts guardan puntos de control en resultados/ y se reanudan si se interrumpen.
