10. Preprocesamiento y Pipeline (2.9)#

Todo el preprocesamiento vive en un Pipeline de scikit-learn (src/modelos.py) que se ajusta solo con el entrenamiento, o con la parte de ajuste de cada pliegue. Este capítulo documenta cada decisión y el hallazgo del EDA que la motiva, y elige con validación cruzada temporal las dos decisiones que no se pueden fijar a priori:

  1. cómo imputar las magnitudes faltantes;

  2. qué conjunto de variables usar.

10.3 Elección por validación cruzada temporal (solo entrenamiento)#

Se usa la validación cruzada temporal de ventana creciente con gap del capítulo 7: 5 pliegues sobre el último 60 % de los meses de entrenamiento. El modelo es el SVR lineal base con C = 0,1; su hiperparámetro se ajusta en el capítulo 11. Se compara el RMSLE medio de los pliegues.

# Selección de la imputación y del conjunto de variables por CV temporal (RMSLE)
def cv_rmsle(cols, imput="constante", C=0.1):
    r = []
    for a, v in pl:
        m_ = mdl.svr_lineal(cols, C=C, imputacion_magnitud=imput).fit(X.iloc[tr[a]][cols], y[tr[a]])
        r.append(ev.rmsle(y[tr[v]], m_.predict(X.iloc[tr[v]][cols])))
    return np.mean(r), np.std(r), r

conjuntos = {
    "todas (18)": list(X.columns),
    "sin calendario (16)": [c for c in X.columns if c not in mdl.CICLICAS],
    "sin lat/lon (16)": [c for c in X.columns if c not in mdl.UBICACION],
    "sin vecindad (16)": [c for c in X.columns if not c.startswith("vec")],
    "sin magnitudes (14)": [c for c in X.columns if c not in mdl.MAGNITUDES],
    "solo conteos propios (7)": ["n_1m", "n_3m", "n_6m", "n_12m", "n35_3m", "n35_12m", "n_mismo_mes_anio_prev"],
}
filas = []
for imput in ("constante", "mediana"):
    mu_, sd_, _ = cv_rmsle(list(X.columns), imput)
    filas.append({"prueba": f"imputación de magnitud: {imput}", "RMSLE_CV_media": mu_, "RMSLE_CV_desv": sd_})
sel_imp = pd.DataFrame(filas)
imput_ok = "constante" if sel_imp.RMSLE_CV_media[0] <= sel_imp.RMSLE_CV_media[1] else "mediana"
filas = []
for nombre, cols in conjuntos.items():
    mu_, sd_, r = cv_rmsle(cols, imput_ok)
    filas.append({"conjunto": nombre, "n_variables": len(cols), "RMSLE_CV_media": mu_, "RMSLE_CV_desv": sd_,
                  **{f"pliegue_{i + 1}": v for i, v in enumerate(r)}})
sel = pd.DataFrame(filas).sort_values("RMSLE_CV_media")
eda.guardar_tabla(sel_imp, "seleccion_imputacion.csv"); eda.guardar_tabla(sel, "seleccion_conjuntos.csv")

Interpretación.

  • Imputación. La constante da el menor RMSLE medio (0,4220 frente a 0,4390). La diferencia es apreciable.

  • Conjunto de variables. El menor RMSLE de validación lo da «todas (18)» (0,4220 ± 0,0310).

  • Regla de un error estándar. Los conjuntos a menos de un error estándar del mejor (umbral 0,4358) son: «todas (18)», «sin lat/lon (16)», «sin calendario (16)», «sin vecindad (16)».

  • Decisión. Se adopta «todas (18)». Las 18 variables están dentro del margen de un error estándar: se conservan por coherencia con el EDA, que justifica cada una, y para que los modelos no lineales del Entregable 2 partan del mismo conjunto.

  • Qué variables importan. Quitar las magnitudes (o quedarse solo con los conteos propios) empeora el RMSLE en 0,028, y esa diferencia se repite en los 5 pliegues. Quitar calendario, ubicación o vecindad no cambia nada para un modelo lineal. En el caso de la ubicación y la vecindad es esperable: su relación con el objetivo es no lineal (capítulos 5 y 8).

  • Variabilidad entre pliegues. La desviación entre pliegues (0,031 en promedio) es comparable a la mayor diferencia entre conjuntos: el error depende mucho del periodo evaluado (el pliegue 2 es el más difícil en todos los conjuntos). Es una señal de los cambios de régimen del capítulo 7.
