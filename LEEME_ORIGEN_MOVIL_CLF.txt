ORIGEN MÓVIL 2021-2026 PARA LAS 26 COMBINACIONES DE CLASIFICACIÓN (correr en tu PC)
==================================================================================

1. Descomprime Entregable2_proyecto.zip y abre "Anaconda Prompt":
       conda activate ml_venv
       cd C:\ruta\a\jbook_sismos
       pip install -r requirements.txt        (solo si no lo has hecho)

2. Verifica que carga:
       python -c "from src import datos, benchmark; print('ok')"

3. Corre (N = núcleos físicos menos 1; con ~8 GB de RAM, no más de 4):
       python scripts/origen_movil_clasificacion.py --trabajos N

   - Paso 1: afina las 26 combinaciones (7 modelos x 4 balanceos, con TPE) con datos anteriores a 2016 (una línea por combinación).
   - Paso 2: reentrena cada combinación en los 6 orígenes 2021-2026 (avisa cada 26 ajustes).
   - Si se interrumpe, vuelve a lanzar el MISMO comando: continúa donde iba.
   - Al final debe decir "Ajustes faltantes: 0".

4. Cuando termine, comprime y envía estas dos carpetas:
       resultados\origen_movil\hp_clf\
       resultados\origen_movil\pred_clf\
